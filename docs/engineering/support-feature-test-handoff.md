## Account-capable phone test setup

The generic debug APK has no identity endpoint, so its anonymous engineering mode cannot save results or exercise account-scoped history, dashboard and reminders. A separate historical local-auth debug APK was built with `http://127.0.0.1:8080`, SHA-256 `58b179345359b98973a8ed3cb5a7a6467e7ea7a2c086bf9ecc11eff6594dc178` (E-20260930-010), but is **not in Git**. Build your own using the commands in [`team-testing-handoff.md`](team-testing-handoff.md). It is for a USB-connected, authorized test phone with `adb reverse`, not distribution or TLS/privacy claims. Use disposable accounts. Configure PostgreSQL and the test SMTP relay using the team guide, start the service on port 8080, then run:

```bash
adb devices
adb reverse tcp:8080 tcp:8080
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Verify backend `/actuator/health` locally, register/verify/login in the app, then run F06/F07/F08/F17/F18 below. For an **offline** F08 check, first remove the USB forwarding with `adb reverse --remove tcp:8080`, disable phone connectivity, force-stop/reopen the app and use the already signed-in local session. Restore forwarding before any new login/reset/account deletion. Reboot may clear forwarding; reminders should continue locally, but reconnect forwarding if server operations are needed. A configured local endpoint and a buildable APK do not prove live phone login until that flow is observed and recorded. An approved HTTPS test deployment can replace this local route in a separately built candidate.

The current release check is `python3 scripts/check_android_privacy.py app/build/outputs/apk/release/app-release-unsigned.apk` after `:app:assembleRelease`. It rejects a debuggable release, enabled backup or cleartext, unexpected permissions and incomplete backup exclusions. A signed release build also requires a valid HTTPS identity endpoint. Both checks are engineering safeguards; they cannot replace runtime traffic, backup, physical notification and human accessibility testing.

Return an anonymous table of **build hash, device ID/model, API, steps, expected, observed, pass/fail and evidence location** for each attempt. Engineering owns reproduction, code fixes and affected regression reruns. Figma visual integration, real cloud/SMTP, signing custody, public policy/contact and Play Console access remain separately tracked in [`decisions-and-blockers.md`](decisions-and-blockers.md).
