Hapus akun daring Carda

Halaman ini hanya menghapus identitas akun, kode verifikasi/reset, dan sesi pada server. Data profil kesehatan, hasil, dan riwayat tersimpan di ponsel. Menghapus akun melalui aplikasi juga membersihkan data lokal akun pada ponsel tersebut.

Jika menghapus akun di sini, hapus data lokal pada setiap ponsel melalui pengaturan Carda atau pengaturan aplikasi Android. Data kesehatan tidak dipulihkan dari server. Tindakan penghapusan akun tidak dapat dibatalkan.
